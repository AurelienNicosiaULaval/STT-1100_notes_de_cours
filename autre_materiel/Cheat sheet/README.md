# Feuille aide-mémoire STT-1100

La feuille aide-mémoire publiée en PDF est générée par `scripts/build_course_cheatsheet.R`.

Ce script télécharge les aide-mémoires Posit pertinents pour les modules du cours, puis les concatène dans:

- `docs/autre_materiel/Cheat sheet/stt1100_cheatsheet_mod.pdf`;
- `docs/en/autre_materiel/Cheat sheet/stt1100_cheatsheet_mod.pdf`.

Les fichiers `stt1100_cheatsheet_mod.qmd` et `stt1100_cheatsheet_mod.tex` sont conservés comme ancienne source locale d'inspection. L'ancienne source PowerPoint et son projet RStudio sont conservés dans `../_archives/cheat-sheet-powerpoint/`.

Source des PDF: <https://rstudio.github.io/cheatsheets/>. Le dépôt Posit Cheatsheets indique une licence Creative Commons; les avis de licence et d'attribution demeurent présents dans les PDF concaténés.
