# Archives internes

Ce dossier regroupe du matériel ancien ou remplacé qui peut encore aider à retracer l'historique du cours, mais qui ne doit pas être présenté comme matériel courant.

- `cheat-sheet-powerpoint/` contient l'ancienne version PowerPoint de la feuille aide-mémoire et son projet RStudio.

Avant de réutiliser un fichier archivé, vérifier s'il est encore cohérent avec les modules actuels, les consignes GitHub et les pages publiques du cours.
