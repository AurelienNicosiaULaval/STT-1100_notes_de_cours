# Support GitHub

Ce dossier contient la version publiée de la présentation GitHub utilisée en classe.

- `Présentation Github.pdf` est la version publiée dans le site du cours.
- La source éditable est conservée dans `../_sources/presentation-github/presentation-github.pptx`.
- Le guide à suivre en priorité pour les étudiants est `../aide-memoire-rstudio-github.qmd`.

Le PDF reste utile pour revoir les concepts de dépôt, commit, push et pull. Les procédures d'authentification et de clonage doivent être maintenues dans l'aide-mémoire RStudio et GitHub.
