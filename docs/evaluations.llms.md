# Comprendre le parcours

Les évaluations de STT-1100 suivent la même logique que les modules: pratiquer un geste, produire une trace claire, recevoir une rétroaction, puis réinvestir ce qui a été appris dans une production plus autonome.

## Parcours d'une session

Cette carte montre comment les pièces d'évaluation s'enchaînent. Les échéances, les fichiers à remettre et les pondérations officielles sont confirmés dans MonPortail.

01

### Avant de remettre

Les aventures, mini-tests et exercices servent à pratiquer. Ils aident à préparer les remises, mais ne remplacent pas les consignes officielles.

02

### Défi 1

Le premier rapport Quarto installe les attentes de base: structure, code lisible, rendu HTML et interprétation courte. La rétroaction est formative.

03

### Défis 2 à 10

Les défis sont des livrables courts reliés aux modules. Ils prolongent l'aventure avec plus d'autonomie et préparent le projet.

04

### Examen

L'examen vérifie l'autonomie sur les gestes essentiels des modules 1 à 4: importer, transformer, visualiser et expliquer.

05

### Projet de session

Le projet rassemble la question, les données, l'analyse, la présentation, le résumé final, la reproductibilité et le travail d'équipe.

## Critères transversaux

Ces critères reviennent dans les défis, l'examen et le projet.

### Reproductibilité

Le document ou le dépôt permet de comprendre et de refaire les étapes essentielles.

### Code lisible

Les objets ont des noms clairs, les transformations sont structurées et le code inutile est retiré.

### Graphiques pertinents

Les choix visuels servent la question posée: titres, axes, unités, légendes et échelles sont soignés.

### Interprétation prudente

Les conclusions disent ce que les données permettent d'affirmer, sans dépasser ce qui est observé.

### Communication

Le livrable est compréhensible pour une personne qui ne vous voit pas travailler.

### Respect des consignes

Le bon fichier est remis, au bon endroit, avec les éléments demandés et sans fichiers inutiles.

## Référence officielle

Le site de cours sert à comprendre la logique pédagogique des évaluations. MonPortail demeure la source officielle pour les dates, les fichiers de remise, les pondérations et les modalités administratives.

### Avant de commencer

Identifier le produit attendu, les données, le format et le lieu de remise.

### Avant de remettre

Rendre le document, vérifier les sorties, relire l'interprétation et retirer les fichiers inutiles.

### Après la rétroaction

Conserver les corrections utiles et les réinvestir dans le prochain défi, l'examen ou le projet.
