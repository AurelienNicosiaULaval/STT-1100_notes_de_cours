## Ce qui revient dans toutes les évaluations

Les formats changent, mais les attentes de fond restent les mêmes.

1

### Reproductibilité

Le fichier doit pouvoir être rendu ou relu sans deviner les étapes suivies.

2

### Code lisible

Les objets ont des noms clairs, les transformations sont structurées et le code inutile est retiré.

3

### Graphiques pertinents

Les choix visuels servent la question posée: titres, axes, unités, légendes et échelles sont soignés.

4

### Interprétation prudente

Les conclusions disent ce que les données permettent d'affirmer, sans dépasser ce qui est observé.
