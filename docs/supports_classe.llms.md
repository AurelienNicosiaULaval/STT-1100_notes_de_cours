## Quel support ouvrir?

Les supports de classe sont là pour accompagner le travail autonome. La bonne question n'est pas seulement “où est le fichier?”, mais “quel support m'aide dans la situation actuelle?”.

### Je démarre le cours

Ouvrir l'aide-mémoire RStudio et GitHub, puis la boîte à outils pour comprendre le workflow de base.

### Je travaille sur un exercice

Garder la feuille aide-mémoire près de soi et consulter les pages données ou packages au besoin.

### Je bloque sur une erreur

Lire le guide “Où et comment chercher”, isoler le problème et poser une question ciblée.

### Je prépare un défi ou le projet

Revenir à la boîte à outils, vérifier le rendu Quarto et sauvegarder le travail si GitHub est demandé.

### Je veux situer le métier

Consulter le panorama des rôles pour relier les gestes techniques au cycle complet d'un projet de données.

### Je veux utiliser l'IA

Lire la page IA avant d'utiliser GPT STT-1100, surtout pour les évaluations et les remises.
