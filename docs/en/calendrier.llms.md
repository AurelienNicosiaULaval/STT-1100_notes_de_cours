## How to read the calendar

Each module follows the same general cycle. Details can vary by session, but the work order remains stable.

1

### Before

Open the learning plan, complete the targeted readings and use the mini-test to check key ideas.

2

### During

Work through the adventure in class: role, data, code, interpretation and decisions to justify.

3

### After

Complete exercises to consolidate in other contexts and prepare the challenge when the module requires it.

4

### Trace

Render documents, check files, push the repository if needed and keep reusable learning.
