# Toolkit

This page gathers routines to reuse throughout the term.

## R and tidyverse

- `readr::read_csv()` to import a CSV file.
- `dplyr::filter()`, `select()`, `mutate()` and `summarise()` to transform data.
- `ggplot2::ggplot()` to build a visualization step by step.
- `tidyr::pivot_longer()` and `pivot_wider()` to reshape a table.

## Quarto

- Check the YAML header.
- Render the document often to catch errors early.
- Keep data files in the module folder or in a clear subfolder.

## GitHub

- Commit small and understandable steps.
- Write precise commit messages.
- Pull changes before pushing when a shared repository is used.
