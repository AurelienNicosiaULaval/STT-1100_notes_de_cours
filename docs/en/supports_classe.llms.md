## Which document should you open?

Class supports are meant to accompany autonomous work. The useful question is not only “where is the file?”, but “which support helps me in the current situation?”.

### I am starting the course

Open the RStudio and GitHub memo, then the toolkit to understand the basic workflow.

### I am working on an exercise

Keep the cheat sheet nearby and consult the datasets or packages pages when needed.

### I am stuck on an error

Read the search guide, isolate the problem and ask a targeted question.

### I am preparing a challenge or project

Return to the toolkit, check the Quarto render and save the work if GitHub is required.

### I want to understand the role

Use the role panorama to connect technical moves to the full data project cycle.

### I want to use AI

Read [the AI page](ia.llms.md), then open [GPT STT-1100](https://chatgpt.com/g/g-682d165f32e881918633affa3fe9dfd6-gpt-stt-1100) with a precise request: *I am preparing this activity. What should I check without you doing the work for me?*
