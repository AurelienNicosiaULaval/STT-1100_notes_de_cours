# Glossary

This glossary gives short landmarks. Detailed definitions are developed in the modules.

| Term | Course landmark |
|----|----|
| Observation | A row or analytical unit in a data table. |
| Variable | A characteristic measured or described for each observation. |
| Tibble | A modern data table used in the tidyverse. |
| Factor | A categorical variable with controlled levels. |
| Join | An operation that combines tables using a common key. |
| Visualization | A graphical representation used to explore or communicate structure in data. |
| Model | A simplified representation of a statistical relation or mechanism. |
| Bias | A possible distortion between what is observed, measured and concluded. |
| Reproducibility | The ability to rerun an analysis and obtain the same results from the same files. |
