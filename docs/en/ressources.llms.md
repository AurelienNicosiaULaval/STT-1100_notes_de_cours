## Books and guides

These references are free or available online. They support readings across several modules.

### R for Data Science, 2nd edition

Hadley Wickham, Mine Çetinkaya-Rundel and Garrett Grolemund. Main reference for tidyverse, import, transformation, visualization, dates, joins and communication.

[Open R4DS](https://r4ds.hadley.nz/)

### Introduction to Modern Statistics

Mine Çetinkaya-Rundel and Johanna Hardin. Complement used for numerical exploration, statistical intuition and applied interpretation.

[Open IMS](https://openintro-ims.netlify.app/)

### The Tidyverse Style Guide

Guide for writing R code that is readable, consistent and easier to review.

[Open the guide](https://style.tidyverse.org/)

### Text Mining with R

Julia Silge and David Robinson. Module 10 reference for turning text into tidy data, computing frequencies and producing lexical analyses.

[Open the book](https://www.tidytextmining.com/)

### Quarto documentation

Official documentation for creating, rendering and publishing Quarto documents and sites.

[Open Quarto Docs](https://quarto.org/docs/)

### GitHub Docs

Official documentation for repositories, commits, issues, branches and GitHub workflows.

[Open GitHub Docs](https://docs.github.com/)

## Readings by module

This summary lists key readings without requiring the full learning-plan page.

### Module 01

[R4DS](#r4ds) to situate the workflow and [Quarto](#quarto-docs) to understand the HTML report.

### Module 02

[Visualization](https://r4ds.hadley.nz/data-visualize.html), [transformation](https://r4ds.hadley.nz/data-transform.html), [EDA](https://r4ds.hadley.nz/EDA.html), [spreadsheets](https://r4ds.hadley.nz/spreadsheets.html) and [IMS chapter 5](https://openintro-ims.netlify.app/explore-numerical).

### Module 03

[R4DS Strings](https://r4ds.hadley.nz/strings.html) and recoding references for categorical variables.

### Module 04

[Import](https://r4ds.hadley.nz/data-import.html), [tidy data](https://r4ds.hadley.nz/data-tidy.html), [factors](https://r4ds.hadley.nz/factors.html), [spreadsheets](https://r4ds.hadley.nz/spreadsheets.html) and [lists](https://r4ds.hadley.nz/rectangling.html).

### Module 05

[EDA](https://r4ds.hadley.nz/EDA.html), [dates](https://r4ds.hadley.nz/datetimes.html) and [tidy data](https://r4ds.hadley.nz/data-tidy.html).

### Module 06

[GitHub Docs](#github-docs), [Quarto Inline Code](https://quarto.org/docs/computations/inline-code.html) and [R4DS Joins](https://r4ds.hadley.nz/joins.html).

### Module 07

[R4DS Communication](https://r4ds.hadley.nz/communication.html) to move from graph to understandable message.

### Module 08

[R4DS Web scraping](https://r4ds.hadley.nz/webscraping.html) to understand HTML, CSS and extraction.

### Module 09

Targeted review of prediction, validation and bias concepts in the module material.

### Module 10

[Text Mining with R](#tidytext), chapters 1 to 3, then [flexdashboard](https://rstudio.github.io/flexdashboard/) and [Shiny](https://shiny.posit.co/) documentation.

## AI and targeted help

GPT STT-1100 can serve as a review, debugging and rephrasing partner. It does not replace your judgment: any answer used must be checked against the code, data and module instructions.

[Open GPT STT-1100](https://chatgpt.com/g/g-682d165f32e881918633affa3fe9dfd6-stt-1100) [View reference material](references.llms.md)

### Explain

Ask for an explanation of an R output, an error message or a learning-plan step.

### Check

Submit your own code or interpretation and ask for targeted feedback.

### Improve

Ask for a clearer variant, then choose what remains coherent with the instructions.
