# Projet de session

Le projet de session rassemble les compétences du cours dans une production plus complète: données, analyse, visualisation, interprétation et communication.

### Énoncé

Consulter les consignes du projet et les attentes générales.

[Ouvrir l’énoncé](../projet_session/enonce_projet.llms.md)

### Préparation

Utiliser les modules comme jalons pour construire progressivement le projet.

[Voir les modules](../modules.llms.md)

## Repères

- Choisir une question claire.
- Documenter les données utilisées.
- Produire une analyse reproductible.
- Interpréter les résultats avec prudence.
- Présenter un produit lisible pour un lecteur externe.
