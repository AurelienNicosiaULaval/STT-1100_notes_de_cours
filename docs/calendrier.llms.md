## Comment lire le calendrier

Chaque module suit le même cycle général. Le détail peut varier selon la séance, mais l'ordre de travail reste stable.

1

### Avant

Ouvrir le plan d'apprentissage, faire les lectures ciblées et utiliser le mini-test pour vérifier les idées clés.

2

### Pendant

Travailler l'aventure en classe: rôle, données, code, interprétation et décisions à justifier.

3

### Après

Faire les exercices pour consolider dans d'autres contextes et préparer le défi lorsque le module le demande.

4

### Trace

Rendre les documents, vérifier les fichiers, pousser le dépôt si nécessaire et conserver les apprentissages réutilisables.

## La règle pratique

Le calendrier ci-dessous indique le chemin de travail. Pour toute question de date, d'heure, de local, de remise ou de pondération, la référence officielle est Brio. Les congés et la période réservée aux examens suivent le calendrier universitaire 2026-2027 de l'Université Laval.

[Revoir le démarrage](demarrage.llms.md) [Boîte à outils](boite_outils.llms.md) [Calendrier ULaval](https://www.ulaval.ca/sites/default/files/notre-universite/direction-gouv/Documents_officiels/Calendrier_universitaire/Calendrier_universitaire_2026-2027.pdf)

### Avant la séance

Vérifier la page du module, les lectures et les fichiers nécessaires.

### Avant une remise

Relire la consigne sur Brio, rendre le document et vérifier le bon fichier ou dépôt.

### Après la rétroaction

Conserver les corrections utiles pour le prochain défi, l'examen ou le projet.
