## Livres et guides

Ces références sont gratuites ou accessibles en ligne. Elles servent de base aux lectures de plusieurs modules.

### R for Data Science, 2e édition

Hadley Wickham, Mine Çetinkaya-Rundel et Garrett Grolemund. Référence principale pour le tidyverse, l'importation, la transformation, la visualisation, les dates, les jointures et la communication.

[Ouvrir R4DS](https://r4ds.hadley.nz/)

### Introduction to Modern Statistics

Mine Çetinkaya-Rundel et Johanna Hardin. Complément utilisé pour l'exploration numérique, l'intuition statistique et l'interprétation appliquée.

[Ouvrir IMS](https://openintro-ims.netlify.app/)

### The Tidyverse Style Guide

Guide pour écrire du code R lisible, cohérent et plus facile à réviser.

[Ouvrir le guide](https://style.tidyverse.org/)

### Text Mining with R

Julia Silge et David Robinson. Référence du module 10 pour transformer du texte en données tidy, calculer des fréquences et produire des analyses lexicales.

[Ouvrir le livre](https://www.tidytextmining.com/)

### Documentation Quarto

Documentation officielle pour créer, rendre et publier des documents et sites Quarto.

[Ouvrir Quarto Docs](https://quarto.org/docs/)

### GitHub Docs

Documentation officielle pour les dépôts, commits, issues, branches et workflows GitHub.

[Ouvrir GitHub Docs](https://docs.github.com/)

## Lectures par module

Cette synthèse reprend les lectures clés sans obliger à ouvrir le plan d'apprentissage complet.

### Module 01

[R4DS](#r4ds) pour situer le flux de travail et [Quarto](#quarto-docs) pour comprendre le rapport HTML.

### Module 02

[Visualisation](https://r4ds.hadley.nz/data-visualize.html), [transformation](https://r4ds.hadley.nz/data-transform.html), [EDA](https://r4ds.hadley.nz/EDA.html), [fichiers Excel](https://r4ds.hadley.nz/spreadsheets.html) et [IMS, chapitre 5](https://openintro-ims.netlify.app/explore-numerical).

### Module 03

[R4DS Strings](https://r4ds.hadley.nz/strings.html) et repères de recodage pour les variables catégorielles.

### Module 04

[Importation](https://r4ds.hadley.nz/data-import.html), [données tidy](https://r4ds.hadley.nz/data-tidy.html), [facteurs](https://r4ds.hadley.nz/factors.html), [tableurs](https://r4ds.hadley.nz/spreadsheets.html) et [listes](https://r4ds.hadley.nz/rectangling.html).

### Module 05

[EDA](https://r4ds.hadley.nz/EDA.html), [dates](https://r4ds.hadley.nz/datetimes.html) et [données tidy](https://r4ds.hadley.nz/data-tidy.html).

### Module 06

[GitHub Docs](#github-docs), [Quarto Inline Code](https://quarto.org/docs/computations/inline-code.html) et [R4DS Joins](https://r4ds.hadley.nz/joins.html).

### Module 07

[R4DS Communication](https://r4ds.hadley.nz/communication.html) pour passer d'un graphique à un message compréhensible.

### Module 08

[R4DS Web scraping](https://r4ds.hadley.nz/webscraping.html) pour comprendre HTML, CSS et extraction.

### Module 09

Relecture ciblée des notions de prédiction, de validation et de biais dans le matériel du module.

### Module 10

[Text Mining with R](#tidytext), chapitres 1 à 3, puis documentation [flexdashboard](https://rstudio.github.io/flexdashboard/) et [Shiny](https://shiny.posit.co/).

## IA et aide ciblée

Le GPT STT-1100 peut servir de partenaire de révision, de débogage et de reformulation. Il ne remplace pas votre jugement: toute réponse utilisée doit être vérifiée avec le code, les données et les consignes du module.

[Ouvrir GPT STT-1100](https://chatgpt.com/g/g-682d165f32e881918633affa3fe9dfd6-stt-1100) [Voir le matériel de référence](references.llms.md)

### Expliquer

Demander une explication d'une sortie R, d'un message d'erreur ou d'une étape du plan.

### Vérifier

Soumettre votre propre code ou votre interprétation et demander une rétroaction ciblée.

### Améliorer

Demander une variante plus claire, puis choisir ce qui reste cohérent avec les consignes.
