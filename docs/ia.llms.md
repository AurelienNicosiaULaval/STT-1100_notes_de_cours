## Bons usages pendant le cours

L'IA est utile quand la question est précise et quand vous gardez une trace de ce que vous vérifiez.

### Expliquer

Demander une explication d'une sortie R, d'un message d'erreur ou d'une étape du plan d'apprentissage.

### Vérifier

Soumettre votre propre code ou votre interprétation et demander une rétroaction ciblée.

### Améliorer

Demander une variante plus claire, puis choisir ce qui reste cohérent avec les consignes et votre analyse.

## Avant d'utiliser une réponse

Une réponse utile doit être compatible avec les consignes, les données et le code réellement exécuté.

1.  Relire la consigne du module ou du défi.
2.  Exécuter le code dans votre propre document Quarto.
3.  Vérifier que les noms de variables, filtres et unités correspondent aux données.
4.  Réécrire l'interprétation avec vos propres mots.
