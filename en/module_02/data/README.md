# Provenance of Module 2 real data

The files are created by `scripts/build_module02_real_data.R`.

- `arbres_repertories_quebec.csv`: a 500-tree extract from [Ville de Québec's public-tree inventory](https://www.donneesquebec.ca/recherche/dataset/34103a43-3712-4a29-92e1-039e9188e915), under CC-BY 4.0.
- `comptages_cyclistes_quebec_2026.csv`: a July 10, 2026 snapshot of totals shown by [Ville de Québec's cycling counters](https://villedequebec.eco-counter.com/). One row represents one counting site, not one day or an individual cyclist.
