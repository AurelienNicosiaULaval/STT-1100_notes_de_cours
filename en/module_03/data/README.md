# Provenance of Module 3 real data

- `requetes_311_montreal.csv`: a 750-row extract from [Montréal's 311 service requests](https://donnees.montreal.ca/dataset/requete-311), under CC-BY 4.0. One row is a request, not necessarily a municipal intervention.
- `plaintes_consommation_quebec.csv`: a 750-row extract from [consumer complaints received by Québec's Office de la protection du consommateur](https://www.donneesquebec.ca/recherche/dataset/liste-des-plaintes-recues), under CC-BY 4.0. A complaint is an unverified allegation, not an established violation.
