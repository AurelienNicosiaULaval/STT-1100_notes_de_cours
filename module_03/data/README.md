# Provenance des données réelles du module 3

- `requetes_311_montreal.csv` : extrait des 750 premières lignes du fichier courant des [demandes de services citoyennes 311 de Montréal](https://donnees.montreal.ca/dataset/requete-311), sous CC-BY 4.0. Une ligne représente une demande, et non nécessairement une intervention municipale.
- `plaintes_consommation_quebec.csv` : extrait des 750 premières lignes des [plaintes reçues par l'Office de la protection du consommateur](https://www.donneesquebec.ca/recherche/dataset/liste-des-plaintes-recues), sous CC-BY 4.0. Une plainte est une affirmation non vérifiée, pas une infraction établie.
