# Provenance des données réelles du module 2

Les fichiers sont créés par `scripts/build_module02_real_data.R`.

- `arbres_repertories_quebec.csv` : extrait de 500 arbres répertoriés par la [Ville de Québec](https://www.donneesquebec.ca/recherche/dataset/34103a43-3712-4a29-92e1-039e9188e915), sous licence CC-BY 4.0.
- `comptages_cyclistes_quebec_2026.csv` : instantané des totaux affichés le 10 juillet 2026 par les [compteurs cyclistes de la Ville de Québec](https://villedequebec.eco-counter.com/). Une ligne représente un site de comptage, et non un jour ou un cycliste individuel.
